# Бот для «Аллодов Онлайн»

Память клиента прочитать нельзя (доступ запрещён), поэтому данные берутся
через официальный API аддонов:

```
игра ── аддон BotBridge (Lua) ── цветные ячейки в углу экрана ── aobot (Python) ── нажатия клавиш
```

- **Аддон** `addon/BotBridge` только читает состояние (здоровье, цель, кулдауны,
  координаты) и рисует его полосой из 13 ячеек 4×4 px в левом верхнем углу.
  Сам ничего в игре не делает: `avatar.RunSpell` и `SelectTarget` аддонам
  разрешены только по клику мышью.
- **Бот** `aobot` снимает этот угол экрана, декодирует данные (с контрольной
  суммой) и нажимает клавиши по `config.toml` (режимы бота добавляются отдельно).

## Установка

1. Python 3.11+ (сторонние пакеты не нужны).
2. Поставить аддон:

   ```
   python -m aobot install
   ```
3. В `addon/BotBridge/Scripts/Config.lua` (или уже в папке игры
   `data\Mods\Addons\BotBridge\Scripts\Config.lua`) впишите названия своих умений в `BOT_SPELLS`.
   Названия, которые видит аддон, он пишет в `Personal\Logs\mods.txt`,
   если в настройках интерфейса включена «Запись ошибок пользовательских дополнений».
4. В главном меню игры включите пользовательские дополнения и войдите персонажем.
   После обновления игры дополнения выключаются, их нужно включить снова.
5. Проверка:

   ```
   python -m aobot diag
   ```
   Должны печататься здоровье, цель и т.д.; «искажение цвета» должно быть 0–2.

## Запуск

Старый бот-фармер (поиск цели, добыча, отдых, команда `run`) удалён: режим фарма
будет построен заново. Доступны команды `install`, `diag`, `assist`, `stats` и `test-input`.
Настройки — `config.example.toml` (скопируйте в `config.toml`). В режиме `assist`
**F12** (`stop_key`) — выход из программы; остальные команды останавливаются Ctrl+C.

Бот — двойным кликом по `assist.bat` (окно не закрывается, видна ошибка).

## Режим боя-помощник

```
python -m aobot assist [--config config.toml] [--dry] [--seconds N] [--log] [--data DIR]
```

Играете вы сами; бот только бьёт ротацией (`[[rotation]]`) текущую цель.

- **Включить:** выберите цель и нажмите **F9** (`[assist].key`). Бот бьёт, пока цель жива.
- **Что его выключает:** цель пропала или убита, смерть персонажа, нажатие клавиш чата
  из `[assist].chat_keys` (по умолчанию Enter и Backspace; `/` не входит в список, чтобы
  не конфликтовать с умениями). Снова включить — F9.
- **Чат:** бот сам следит, открыт ли чат: Enter или Backspace открывают, повторный Enter
  (отправка) или Esc закрывают (`[assist].chat_close_keys`; клик мышью чат не закрывает).
  Пока чат открыт, горячая клавиша не действует, поэтому её можно назначить и на букву
  (`key = "e"`). Если бот ошибся и считает чат открытым — нажмите Esc.
- **Выход из программы:** **F12** (`[safety].stop_key`). Внимание: в игре F12 по умолчанию
  открывает «Сумку и экипировку» — `stop_key` лучше сменить на свободную клавишу.
- Если данные аддона устарели или окно игры не активно, бот ничего не нажимает и
  ждёт; бой при этом остаётся открытым и продолжится, когда данные вернутся.
- Пробный запуск без нажатий: `--dry`; `--seconds N` — выйти через N секунд;
  `--log` — печатать каждую смену статуса отдельной строкой.
- **Журнал боёв** пишется в `data/fights` (папку меняет `--data`): файл
  `fights-ГГГГ-ММ-ДД.jsonl`, по строке на бой, с итогом (`kill`, `switched`, `dropped`,
  `death`, `stopped`).

## Способ ввода

**Клавиши** — только через PS/2, как `#ps2_keyboard` в Clickermann: через драйвер InpOut
(`inpoutx64.sys`) скан-код пишется прямо в контроллер клавиатуры i8042 (команда `0xD2` в
порт `0x64`, байт в `0x60`), и Windows получает его как от настоящей PS/2-клавиатуры.
Нужны PS/2-контроллер (есть почти во всех ноутбуках) и драйвер InpOut — Clickermann ставит
его сам. Обычный `SendInput` и драйвер Interception игра не принимает, поэтому их в боте нет.

**Мышь** (`move`, `move_to`, `click`, `mouse_down/up`) — раздел `[input]`, поле `mouse`:

- `sendinput` (по умолчанию) — SendInput с абсолютными координатами, как `MOVE`/`LCLICK`
  обычного режима Clickermann. В игре так **двигается курсор, но клики не проходят**
  (проверено 17.11.2026).
- `ps2` — пакеты PS/2-мыши (команда `0xD3`), как `#ps2_mouse` в Clickermann: клики игра
  принимает, но нужна живая PS/2-мышь. На этом ноутбуке это тачпад ELAN, а у него отключён
  шлейф («ELAN Input Device» в ошибке «устройство не найдено»), поэтому сейчас не работает
  ни у бота, ни у Clickermann. Непринятый байт мыши блокирует весь PS/2-контроллер (и
  клавиши); бот такие «ничьи» байты вычитывает сам.

«Управление указателем с клавиатуры» Windows (Mouse Keys, клик `num5`) в игре тоже не
кликает. Бот сам мышь пока не использует.

Проверка (через 5 с: нажмёт «1» три раза; `--mouse` — сдвинет курсор на 100 px и обратно;
`--click` — кликнет там, где курсор, `--click X Y` — в точке экрана):

```
python -m aobot test-input --key 1
```

Как именно программа шлёт ввод, показывает шпион `python tools/input_spy.py [секунд]`:
он печатает события мыши и клавиатуры с пометкой, программные они или настоящие.

## Ограничения

- **Клиент не принимает программные нажатия клавиш и клики** (проверено 17.11.2026 на
  версии 6.02.2605): `SendInput` проходит в Windows, но персонаж не реагирует. Поэтому
  клавиши идут только через PS/2 (см. «Способ ввода»).
- Окно игры должно быть видно (не свёрнуто и не перекрыто в левом верхнем углу).
- Навигации по маршрутам нет: координаты передаются, но бот по ним не ходит.
- В PvP-активностях не проверялся.
- Автоматизация нарушает правила игры, аккаунт могут заблокировать.

## Тесты

```
python -m unittest discover -s tests -t .
```

Lua-часть аддона проверяется через LuaJIT из документации игры (`tools/luajit`):
упаковщик сверяется с Python байт в байт, а `Main.lua` гоняется на заглушках
со строгими глобалами, как в клиенте.

Если игра не примет сгенерированную текстуру (ячейки не видны), пересоберите
`addon/BotBridge/Textures/White.tga` штатной утилитой `Mods\UITextureConvertEditor.exe`
(тип UISingleTexture).
